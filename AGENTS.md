# Comfety

Android only. Expo SDK 58 and TypeScript. This slice is the home screen, the mixed-sentence listen test, and Speak for a typed reply. Listen uses Scribe v2 Realtime, Urdu with English as the secondary language, and background-audio filtering. Speak sends the typed string unchanged to Eleven v4 Turbo and plays it in the last chosen premade voice. Saved replies use that same path and stay on the phone. Guide talk answers with Grok, then speaks that answer. A lost phrase such as سمجھ نہیں آئی asks for shorter words and one example. What’s in front of me, Read this, and Check the ground each take one photo, then speak. Check the ground only says stairs, an open drain, a vehicle, a person, none, or unsure, and it never says the way is clear. A medicine label ends with the no-dosage line. The camera stays off until you ask. Watch obstacles does not run in Expo Go and does not invent a close-person warning. The YOLO11n int8 model is in the project for a later preview APK. Expo Go still says it is not watching. The recognizer stays off while that audio plays.

Do not put API keys in the app or in git. The listen server reads `ELEVENLABS_API_KEY` from `.env.local`. Do not deploy the worker, and do not run EAS, unless the task says to.
