# Comfety

Android only. Expo SDK 58 and TypeScript. This slice is one home screen: Talk, Guide, permission sentences, and a bundled Noto Nastaliq Urdu line.

Do not put API keys in the app or in git. The Cloudflare Worker in `worker/` is a health-route stub. Do not deploy it, and do not run EAS, unless the task says to.
